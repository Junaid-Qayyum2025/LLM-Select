LLM Specification and Implementation Details
To ensure reproducibility and methodological clarity, this study uses a fixed, controlled configuration of the underlying large language model. All semantic scoring, prompt evaluations, and embedding computations were performed using GPT-4.1 (OpenAI, 2024 release). The model was executed through the OpenAI API with the following deterministic settings:
•	Temperature: 0.1
•	Top-p: 0.95
•	Maximum tokens per call: 512
•	Repetition penalty: disabled
•	Prompt structure: standardized 4-block template with description, statistical summary, domain tags, and ranking instruction
These fixed parameters ensure stable LLM outputs across repeated runs and avoid semantic drift during feature scoring.
To assess the impact of model choice on semantic scoring quality, preliminary experiments were conducted using GPT-4.1, GPT-3.5, and Llama-2-70B. GPT-4.1 consistently produced higher semantic discrimination and more stable feature rankings, with an average improvement of 3 to 7 percent in semantic coherence scores compared to the alternatives. GPT-3.5 and Llama-2 exhibited higher variance in ranking stability and required additional prompt retries, increasing computational time by approximately 18 to 25 percent. These observations justify the use of GPT-4.1 as the primary scoring model, as it provides a better balance between semantic accuracy and computational efficiency.
Embedding Model and Similarity Computation:
The semantic similarity and embedding-level relevance scores were computed using the OpenAI text-embedding-3-large model. This embedding model provides high-dimensional semantic vectors suitable for measuring feature relationships. Cosine similarity was used as the primary distance metric due to its robustness for high-dimensional embedding spaces.
•	Embedding dimension: 3,072
•	Similarity metric: cosine similarity
•	Normalization: unit vector normalization applied prior to similarity evaluation
Parameter Justification and Optimization Settings
The fusion weights used in the final importance score—α (semantic), β (statistical), γ (domain)—were selected using Bayesian Optimization. The search was conducted over 50 trials with validation accuracy as the objective function.
•	Search space:
o	α ∈ [0.2, 0.6]
o	β ∈ [0.2, 0.6]
o	γ ∈ [0.0, 0.4]
•	Best-performing configuration:
o	α = 0.48
o	β = 0.39
o	γ = 0.13
•	Number of optimization iterations: 15
All statistical scores (MI, χ², correlations, variance) were normalized using Z-score normalization to avoid scale imbalance during score fusion.
